# Fișiere de referință

Acest director conține materiale utile pentru analiză și verificare, dar care
nu sunt folosite ca intrări în procesul automat de build:

- `Cartile_VT_NT.txt` — inventarul istoric al titlurilor cărților biblice;
- `osis2mod.output` — ieșirea unei rulări anterioare `osis2mod`, păstrată pentru
  consultarea problemelor de versificare.

Sursele efective ale modulului SWORD sunt exclusiv cele două fișiere UTF-8 din
directorul `sources/`.
